# Fictional demo support policy

This document is sample public-to-all-customers knowledge-base content for a test
agent. It does not describe a real store or create a real refund entitlement.

For the default demo configuration, paid, shipped, and delivered orders may receive
simulated refunds. Each refund must be positive, no more than USD/EUR/GBP 100.00
(JPY 10,000), and no more than the order's remaining refundable balance. USD, EUR,
and GBP amounts allow two decimal places; JPY amounts allow no fractional yen.
Pending and cancelled orders are ineligible. There is no time-window restriction
in this demo. The backend's configured rules remain authoritative.

The customer must request a refund and provide a reason. Support checks the order
before issuing it and confirms success only after the local ledger transaction
commits. These refunds never move real funds.

For a headset with no sound, verify its connection, select the correct output
device, check application/system volume and mute controls, then test another audio
source. If it still fails, describe the issue to support and include the order ID.

Interaction summaries help with continuity, but generated narrative cannot prove
that a refund happened. The order's current refund history is the transaction record.
